# Prayer Times — On-Demand Tafseer Archives

Compressed (`.ndjson.xz`) Arabic Tafseer bundles fetched on demand by the `flutter_quran` package and cached offline in the user's application support directory after download.

## Included Books

| ID | Name | Author | File |
| :--- | :--- | :--- | :--- |
| `saadi` | تيسير الكريم الرحمن | الشيخ عبد الرحمن السعدي | `saadi.ndjson.xz` |
| `baghawi` | معالم التنزيل | الإمام الحسين بن مسعود البغوي | `baghawi.ndjson.xz` |
| `ibn_kathir` | تفسير القرآن العظيم | الإمام ابن كثير | `ibn_kathir.ndjson.xz` |
| `wasit` | التفسير الوسيط | فضيلة الشيخ محمد سيد طنطاوي | `wasit.ndjson.xz` |
| `qurtubi` | الجامع لأحكام القرآن | الإمام القرطبي | `qurtubi.ndjson.xz` |
| `tabari` | جامع البيان في تأويل القرآن | الإمام الطبري | `tabari.ndjson.xz` |

Note: Lightweight `muyassar.ndjson.xz` and `jalalayn.ndjson.xz` remain bundled inside the Android APK for instant zero-network first-open support.
